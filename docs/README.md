# Robata Documentation

This directory contains development documentation. Production deployments do not require these files.

## Structure

- `adr/` - Architecture Decision Records
- `architecture/` - Public architecture documentation (simplified)
- `conformance/` - Compliance test documentation
- `references/` - External reference materials

## Internal Documentation

Detailed WP progress, performance benchmarks, and implementation status have been moved to the internal archive. Contact maintainers for access.

## Key Documents

| Document | Location | Description |
|----------|----------|-------------|
| Requirements | `REQUIREMENTS.md` (root) | Product requirements (Chinese) |

| ADRs | `adr/` | Architecture decision records |
